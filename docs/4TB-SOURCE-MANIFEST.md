## qPCR primer correction (30 September 2026)

The qPCR Planner source now offers **Working (10 µM)** and **Stock (100 µM)**
for forward and reverse primers. Stock uses one tenth of the working-solution
volume; water compensates for the difference. The existing primer dose, TaqMan
probe recipe, well layout, and mix overage behavior are preserved. Computed
results display the primer concentration used, even if the selector changes
before another calculation.

The qPCR frontend and backend in this checkout's generated `apps/qpcr-planner/`
bundle were refreshed from `b13675d`. The installed desktop application was not
replaced by this source update; a new application build is needed to deliver
the correction to that copy.
